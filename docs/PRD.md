# 技集 Skill Atlas｜產品需求文件

**狀態：** 第一批已由使用者驗收；第二批已實作並通過本機測試，待使用者驗收
**目標使用者：** 希望用中文理解 AI Skills 的 Codex／Claude Code／Cursor 開發者與初學者

## 一、問題與定位
英語 Skill 集合網站可提供名稱、來源與排名，但中文用戶通常不知道 Skill 的具體作用、何時使用、是否需要明確指定名稱及怎樣提出高質量要求。本站不是平台替代品，而是中文解說與使用教學入口。

## 三、非目標
不連接用戶 AI 工具、不代為安裝 Skill、不遠端執行腳本；V1 不做帳號、收藏、線上執行 Skill、AI 即時提示詞生成器、付費功能。

## 四、資料
- 第 1 批：精選且具真實來源的一組 Skill，中文摘要、使用場景、提示詞由本站編輯撰寫並核對。
- 第 2 批：使用 GitHub 公開 REST API 建立來源 SHA 快照與手動增量同步；無憑據時不連 skills.sh API，也不透過未授權爬取繞過登入。作者更新後中文內容標記待複核。
- 任何排序或統計均清楚標示資料基準；沒有來源就不顯示具體安裝量。

## 五、第一批驗收流程
1. 開首頁，以「網頁」或「React」等詞搜尋，驗證列表結果可變更、清除。
2. 點分類，打開一張 Skill 詳細頁，閱讀中文適用場景及限制。
3. 複製安裝命令、調用範例，檢查來源連結；再在手機寬度測試版面。

## 六、第二批驗收（2026-11-03）

第二批的 R07、R08 已實作並完成本機自動測試，等待使用者確認；是否符合中文編輯品質以使用者驗收為準。

1. 首頁收錄至少 100 個 Skill；本次為 117 個，具有 GitHub 原始檔案 SHA／路徑與編輯中文內容。
2. 詳細頁應顯示原始 SKILL.md 連結、核對日期、來源版本，並能複製正確安裝命令與中文使用示例。
3. 執行 `npm run sync:skills` 時，未變動項目應使用快取；GitHub API 失敗或中文資料缺漏時不得覆蓋舊快照。
4. 確保舊搜尋、分類、手機版、404 不回歸；測試與驗收紀錄參見 `docs/PROGRESS.md`。
5. 本站不透過用戶帳號連接 Codex，不提供一鍵安裝；未串接 skills.sh 的 OIDC API，不展示未核實安裝量。

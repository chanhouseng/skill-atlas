# 技集 Skill Atlas｜產品需求文件

**狀態：** 已確認方向；第一批實作中
**目標使用者：** 希望用中文理解 AI Skills 的 Codex／Claude Code／Cursor 開發者與初學者

## 一、問題與定位
英語 Skill 集合網站可提供名稱、來源與排名，但中文用戶通常不知道 Skill 的具體作用、何時使用、是否需要明確指定名稱及怎樣提出高質量要求。本站不是平台替代品，而是中文解說與使用教學入口。

## 二、V1 需求
| ID | 需求 | 驗收條件 | 批次 |
|---|---|---|---|
| R01 | 中文首頁與分類 | 能看到分類並進入清單 | 1 |
| R02 | 中文／英文關鍵字搜尋 | 名稱、中文摘要、標籤可搜尋，無結果有提示 | 1 |
| R03 | Skill 詳細頁 | 有真實來源、用途、場景、安裝方法與提示詞 | 1 |
| R04 | 一鍵複製 | 安裝命令與調用示例可複製，失敗提示清楚 | 1 |
| R05 | 來源可信 | 有 GitHub 與 skills.sh 原始頁面，無虛構安裝量／審計 | 1 |
| R06 | 響應式與鍵盤可用 | 390px 不橫向溢出，輸入、篩選、複製可鍵盤操作 | 1 |
| R07 | 首批約 100 條實際 Skill | 全部來源核對、中文摘要有人為確認 | 2 |
| R08 | 同步與增量更新 | 來源拉取、去重、失敗回退、顯示更新日期 | 2 |
| R09 | 用戶需求導向推薦 | 以中文需求找到較相關的 Skill | 3 |
| R10 | 簡體／繁體顯示切換 | 兩種中文文字均可切換 | 後續 |

## 三、非目標
不連接用戶 AI 工具、不代為安裝 Skill、不遠端執行腳本；V1 不做帳號、收藏、線上執行 Skill、AI 即時提示詞生成器、付費功能。

## 四、資料
- 第 1 批：精選且具真實來源的一組 Skill，中文摘要、使用場景、提示詞由本站編輯撰寫並核對。
- 第 2 批：評估 skills.sh 需驗證的 API 與 GitHub 資料來源；必要時只在伺服器端持有 Vercel OIDC。不要透過未授權爬取繞過登入。
- 任何排序或統計均清楚標示資料基準；沒有來源就不顯示具體安裝量。

## 五、第一批驗收流程
1. 開首頁，以「網頁」或「React」等詞搜尋，驗證列表結果可變更、清除。
2. 點分類，打開一張 Skill 詳細頁，閱讀中文適用場景及限制。
3. 複製安裝命令、調用範例，檢查來源連結；再在手機寬度測試版面。

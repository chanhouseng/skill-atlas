# 技集｜已知風險與技術債（截至 2026-11-03）

## 第二批已處理
- **資料量（第一批的產品限制，已改善）：** 第一批 38 個來源擴充至 117 個，均有 GitHub SKILL.md 路徑、blob SHA 與核對日期。這仍非 skills.sh 全量收錄。
- **同名 Skill（第一批限制，已改善）：** 使用 `owner/repo/slug` 當唯一身份，避免不同倉庫同名條目互相覆蓋。
- **來源更新（第一批限制，已改善）：** 手動 GitHub SHA 增量同步成功；失敗時保留舊快照，內容更新則標記中文稿待複核。
- **BUG-001（第一批已解決）：** Next.js 16 的動態路由需要 `export const instant = false`，已確認不存在的 Skill 返回真正 HTTP 404。第二批回歸驗收仍通過。

## 尚未完成或風險
- **外部資料廣度（產品限制）：** 目前選取 8 個公開倉庫的 117 個項目；不是技能市場全量。新增來源須先核對原始 SKILL.md 並補齊中文條目。
- **中文內容品質（待人工審查）：** 中文用途、示例由 AI 輔助編輯整理，非原作者正式翻譯或人工全面審校；新增／變更來源後應人工檢查，再更新 `reviewedSha`。
- **GitHub API 限額與連線：** 無 token 時 GitHub REST API 有匿名速率限制，raw.githubusercontent.com 在本機曾連線失敗，已改採 REST blob API；限額耗盡時 CLI 會停止並保留上次快照。
- **同步執行方式：** 目前為維護者手動觸發，沒有排程、GitHub Webhook 或線上後台；網站部署前需設計可靠的後端/CI 權限與排程方案。
- **skills.sh API（尚未對接）：** 官方接口需要 Vercel OIDC；不繞過驗證、不展示未核實安裝量和安全分數。
- **安全審核（尚未完成）：** GitHub 來源存在不代表第三方 Skill 安全，尚未完整審查所有依賴、可執行腳本或實際安裝效果。
- **套件安全提示：** 初次安裝時 `npm audit` 有 16 項 moderate，來源為 ESLint 與其開發依賴；生產依賴的 `npm audit --omit=dev` 為 0 項。避免以 `npm audit fix --force` 直接引入破壞性更新，未來核對相容修補。
- **單元測試覆蓋：** 已驗證核心同步純函式和瀏覽器流程，但尚未在真實 GitHub 模擬 SHA 已變更的完整遠端到 UI 工作流程；現有純函式測試涵蓋 SHA 改變的分支。

## 第三批新增記錄（2026-11-03）

- **GitHub API 訪問限額（已觀察到，未解決）：** 首次對公開 repository search 的匿名批量請求出現 GitHub API rate limit；本機候選 JSON 原子寫入保護生效。可用授權 Token 提高 API 限額，但不得在程式碼中保存 Token。
- **GitHub 全量覆蓋（產品不可能保證）：** GitHub 沒有完整 Skills 登記 API；目前 discovery 是多種倉庫關鍵字查詢＋樹核對，不保證抓到所有倉庫或所有 SKILL.md。
- **每週排程運行環境：** Windows Scheduler 已設定，但電腦關機、連線中斷、token 限額耗盡可能導致延期／失敗。若未來上雲，改用 GitHub Actions/CI，PR 仍需人工審核；現階段雲端工作流程未啟用。
- **GitHub Actions 供應鏈（已收緊，待遠端驗證）：** workflow 使用的三個 Action 已固定到明確 commit，checkout 不保留認證，`npm ci` 禁止 lifecycle script。仍需在 GitHub 倉庫啟用 Actions 建立 PR 權限後，以手動觸發驗證實際權限與 PR 行為。
- **候選與正式收錄隔離（已實作）：** 新發現的 20 個項目只有來源檔案路徑已核對，未做安全/內容審核；正式 Skill 數仍為 117。
- **自然語言匹配能力邊界：** 固定同義詞規則能解釋推薦，但對新概念、複雜否定與含糊任務的覆蓋有限，應持續評估實際命中率；不能描述為完整語意搜尋。

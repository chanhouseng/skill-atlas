# Skill Atlas 中文技能目錄設計

## 使用者目標
希望不用先懂英文或知道英文 Skill 名稱，就能找到適合自己的 AI Skills，明白「有何用、何時用、怎樣用」，並自行前往 Codex／Claude Code／Cursor 使用。

## 核心交互
首頁直接可用搜尋框；左方／橫向提供類別；以簡短中文卡片快速評估。點擊進詳細頁，依序讀中文說明、適用場景、安裝指令、最佳調用示例及來源。網站不需要用戶授權任何外部 AI 帳號。

## 導覽與資訊架構
- `/` 首頁、搜尋及分類
- `/skills/[slug]` 詳細頁
- `/about` 使用說明、來源與隱私提醒

## 第一批技術決定（開發者選擇，不代表用戶指定）
- Next.js App Router + TypeScript + Tailwind CSS（方便之後導入 SEO 與資料來源）。
- 首批精選靜態 JSON／TypeScript 型別資料，確保離線可用與成本為零。
- 依 Skill 英文名稱 slug 建立頁面；如果後續發現同名 Skill，升級為來源組合 ID。
- 搜尋即時在瀏覽器端執行；未接入 skills.sh 需 OIDC 的即時 API，避免假數據。
- 不放置虛構用戶評價與安裝量，不聲稱已完成第三方安全審查。

## 介面設計方向
概念：「給 AI 開發者用的中文索引」，像精心編排的開發工具目錄，而非 SaaS 宣傳頁。
- 主色為深海軍藍 #0E2038、背景 #F5F7FA、白色 #FFFFFF、點綴青綠 #21A9A3、正文 #17263C、淺灰 #66758B。
- 清楚分層字體（中文系統字型），標題適度放大，資訊密度適中；不用裝飾性漸變背景。
- 只有搜尋、分類與卡片互動；動畫以淡入與微移動為限，尊重減少動態偏好。
- 主要行動：找到一個有用的 Skill 並查看指南；不存在多個互相競爭的 CTA。

## 風險與取捨
- skills.sh API 正式文件要求 Vercel OIDC；第一批不會伪裝成即時排行榜。
- 初始收錄數低於 100 時明示「首批精選」，下一批擴增並驗證來源。
- 避免把生成的示例稱為官方最佳提示詞；標記「編輯建議」。
